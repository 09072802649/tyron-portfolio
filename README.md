## 🎨 Design System & Visual Concept

- **Concept**: *Cyber-Tech Dark Glassmorphism*
- **Base Canvas**: Deep Cyber Slate (`#080C14`) with subtle ambient glowing background grids and animated gradient blobs.
- **Glassmorphic Surfaces**: `rgba(15, 23, 42, 0.72)` with `backdrop-filter: blur(14px)` and fine borders (`rgba(255, 255, 255, 0.08)` / cyan glow on hover).
- **Accents**: Neon Cyan (`#00F2FE`), Electric Blue (`#4FACFE`), Tech Purple (`#7F00FF`).
- **Typography**: Google Font **Inter** for clean readability, Google Font **JetBrains Mono** for code tags, credentials, and technical metadata.
- **Iconography**: FontAwesome 6 Free CDN.
