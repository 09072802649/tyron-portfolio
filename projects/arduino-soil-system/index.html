Arduino: Soil Moisture Sensor for Plants Modified w/ Audio Speaker Alert

A micro-controlled plant hydration management system developed for Datamex College of Saint Adeline. Interfacing an analog resistive soil moisture probe with an Arduino Uno R3, dual status indicator LEDs (Green/Red), and acoustic frequency alerts (1000Hz / 1500Hz) to prevent dehydration in high-temperature environments.

CONTROLLER MCU: ATmega328P

Arduino Uno R3 Microcontroller

Pin Roles: A0 (Analog In), D1 (Green LED), D3 (Red LED), D5 (Speaker PWM), 5V & GND

Specs: 16 MHz Clock, 32KB Flash, 2KB SRAM, 14 Digital I/O, 6 Analog Inputs

Electrical Function:

Central computing unit executing C++ logic, sampling analog-to-digital converter channels, and driving output peripherals via PWM square waves.

Role in Project:

The brain of the system. Reads probe data from pin A0, executes moistureDetection(), calculates saturation ratio, and drives the LEDs and speaker.

Enlarge Photo Resistive / Capacitive
ANALOG SENSOR Signal: 0–1023 ADC

Soil Moisture Sensor Probe

Pin Roles: SIG → Arduino Analog Pin A0, VCC → 5V Power, GND → System Ground

Specs: Dual conductive trace probes, variable resistance voltage divider output

Electrical Function:

Measures soil conductivity between two prongs; water lowers electrical resistance while dry soil creates high electrical resistance.

Role in Project:

Inserted directly into the plant pot soil to capture real-time moisture data and supply raw ADC voltage to the Arduino's A0 pin for ratio evaluation.

Enlarge Photo PWM Synthesized
AUDIO TRANSDUCER PWM Output

Acoustic Speaker / Piezo Transducer

Pin Roles: Positive Lead (+) → Arduino Digital Pin D5 (PWM), Negative Lead (-) → GND

Specs: 1000 Hz, 1500 Hz, 5000 Hz audible square wave frequencies

Electrical Function:

Converts rapid square wave voltage pulses generated by tone() on PWM pin 5 into acoustic vibrations via piezoelectric ceramic disc flexion.

Role in Project:

Replaced basic buzzers with custom acoustic tones: emits 1000Hz alert (≤10% moisture: "I'm Thirsty"), 1500Hz chirp (>30%: "I'm Full"), and startup chimes.

Green Status LED (5mm)

Pin Roles: Anode (+) → Arduino Digital Pin D1 (via 330Ω Resistor), Cathode (-) → GND

Electrical Function:

Semiconductor P-N junction emitting green photons through electroluminescence when forward biased by 5V logic HIGH.

Role in Project:

Visual indicator for adequate/optimal hydration. Illuminates brightly when the plant has sufficient water, signaling healthy soil conditions.

Step-by-Step Guide to Build Arduino Plant Hydration System

Follow stages sequentially from Stage 1 (Power Rails) to Stage 6 (Live Testing).
STAGE 01 POWER RAILS

Common Power Rails & Ground Bus

View Step Image 5V & GND

1. Mount the Arduino Uno R3 next to the solderless breadboard on an anti-static work mat.

2. Connect a red DuPont jumper wire from the Arduino 5V pin to the breadboard's red positive (+) power rail.

3. Connect a black jumper wire from the Arduino GND pin to the blue negative (-) ground rail.

Rail Pinout: Arduino 5V → Breadboard (+)
Ground Pinout: Arduino GND → Breadboard (-)
STAGE 02 SENSOR WIRING

Soil Moisture Sensor & Analog Pin A0

View Step Image Pin A0 Signal

1. Connect sensor header VCC to the breadboard 5V (+) power bus.

2. Connect sensor header GND to the breadboard Ground (-) bus.

3. Connect sensor SIG / AO (Analog Output) via yellow jumper wire directly to Arduino Analog Pin A0.

4. Keep probe prongs clean and dry for baseline zero calibration.

Analog Signal: Sensor AO → Arduino Pin A0
Sensor Power: 5V & GND Rails
STAGE 03 LEDS & RESISTORS

Dual LEDs & Resistor Protection

View Step Image Pins D1 & D3

1. Insert **Green LED** on breadboard. Connect longer anode lead (+) to Arduino Pin D1 via a 330Ω resistor. Connect shorter cathode (-) to GND.

2. Insert **Red LED** on breadboard. Connect longer anode lead (+) to Arduino Pin D3 via a 330Ω resistor. Connect shorter cathode (-) to GND.

3. Verify polarity: Shorter lead / flat rim is cathode (-).

Green LED: Arduino D1 → 330Ω → Anode (+)
Red LED: Arduino D3 → 330Ω → Anode (+)
STAGE 04 SPEAKER PWM

Acoustic Piezo Speaker (Pin D5)

View Step Image PWM Tone Out

1. Connect speaker positive terminal (+ / red wire) directly to Arduino Digital Pin D5.

2. Connect speaker negative terminal (- / black wire) to the breadboard Ground bus.

3. Note: Pin D5 is PWM-capable, allowing the ATmega328P timer to synthesize exact square wave frequencies (1000Hz, 1500Hz, 5000Hz, 6000Hz).

Speaker (+) Lead: Arduino Pin D5 (PWM)
Speaker (-) Lead: Common Ground Rail (GND)
STAGE 05 CODE UPLOAD

Arduino IDE Sketch Flashing

View Step Image 9600 Baud UART

1. Connect Arduino Uno to your computer using the USB Type-A to Type-B cable.

2. Open Arduino IDE, select Tools > Board > Arduino Uno and choose your active COM port (e.g. COM4).

3. Paste the C++ sketch from the code inspector below and click Upload (Ctrl+U).

4. Open Serial Monitor (Ctrl+Shift+M) and verify 9600 baud rate.

Board Target: Arduino Uno (ATmega328P)
Serial Stream: 9600 bps UART

C++ Arduino Source Code

Full sketch code programmed, calibrated, and flashed via Arduino IDE.

arduino_soil_moisture_speaker.ino
Arduino C++ 
int greenLight = 1;      // Pin for Green LED (Normal & Optimal moisture)
int redLight = 3;        // Pin for Red LED (Dry soil alert)
int speakerPin = 5;      // Pin for Piezo Speaker / Buzzer
int maximumMoistureLevel = 1023; // Maximum analog reference ceiling
int currentMoistureLevel; // Reading from soil probe (pin A0)

void moistureDetection() {
  float moistureRatio = (float)currentMoistureLevel / (float)maximumMoistureLevel;

  // Case 1: DRY SOIL (<= 30% moisture)
  // Beeping buzzer alarm + Voice prompt: "My soil is dry"
  if (moistureRatio <= 0.30) {
    digitalWrite(greenLight, LOW);  // Turn off green light
    digitalWrite(redLight, HIGH);   // Turn on red alert light
    for (int i = 0; i < 3; i++) {
      tone(speakerPin, 1000, 100);  // 1000Hz dry beep
      delay(160);
    }
    Serial.println(F("[VOICE PROMPT]: My soil is dry"));
  } 
  // Case 2: NORMAL WATER (31% to 75% moisture)
  // Status chime + Voice prompt: "My soil is wet"
  else if (moistureRatio <= 0.75) {
    digitalWrite(greenLight, HIGH); // Turn on green light
    digitalWrite(redLight, LOW);    // Turn off red light
    tone(speakerPin, 1500, 300);    // 1500Hz normal water chime
    Serial.println(F("[VOICE PROMPT]: My soil is wet"));
  }
  // Case 3: TOO MUCH WATER / DROWNING (> 75% moisture)
  // High-frequency siren + Voice prompt: "My soils drowning"
  else {
    digitalWrite(greenLight, HIGH); // Both LEDs signal flood state
    digitalWrite(redLight, HIGH);
    tone(speakerPin, 2600, 90);     // 2600Hz siren pulse
    delay(110);
    tone(speakerPin, 2000, 90);
    Serial.println(F("[VOICE PROMPT]: My soils drowning"));
  }
}

void setup() {
  // Initialize output pins for LEDs and speaker
  pinMode(greenLight, OUTPUT);     // Pin for Green LED
  pinMode(redLight, OUTPUT);       // Pin for Red LED
  pinMode(speakerPin, OUTPUT);     // Pin for Speaker

  // Initialize the soil moisture sensor pin (A0)
  pinMode(A0, INPUT);

  // Initialize moisture level (calibrated to maximum level)
  maximumMoistureLevel = analogRead(A0);

  // Initial sound to indicate that the program has started
  tone(speakerPin, 5000, 500);  // High pitch for startup sound
  delay(200);                   // Small delay to separate the sounds
  tone(speakerPin, 6000, 500);  // Another indication sound
  delay(600);                   // Delay to allow the sound to finish

  Serial.begin(9600);
}

void loop() {
  // Read the current moisture level from the sensor
  currentMoistureLevel = analogRead(A0);

  // Call moistureDetection to determine what light and sound to play
  moistureDetection();

  // Short delay to prevent overloading the microcontroller
  delay(100);

  // Print the current moisture level to the Serial Monitor
  Serial.println(currentMoistureLevel);
}
